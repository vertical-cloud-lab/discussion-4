# Yellow Star with "FIRMWARE" — Design

A text-only (ASCII) design for a yellow paper five-pointed star with the
word **FIRMWARE** written in ALL CAPS across the body of the star, plus a
silver string threaded through a small punch-hole near the top point so the
star can hang.

> Color note: The construction paper used is **YELLOW**, and the threading
> string is **SILVER**. Because this design must be text-only, the colors
> are documented here rather than rendered.

## The Design (ASCII)

```
             ~~~~~~~~~~          <- silver string, looped above the star
            ~          ~
                 *                <- punch-hole near the top point
                / \
               /   \
              /     \
       _____ /       \ _____
      \                     /
       \    F I R M W A R E /
        \                  /
         \                /
         /                \
        /                  \
       /                    \
      /__/\              /\__\
        /  \            /  \
       /    \          /    \
      /______\        /______\
```

The label `FIRMWARE` sits horizontally on a single line across the upper
body of the star, just below the punch-hole and the top point, in all
capital letters and letter-spaced so it spans the widest part of the star
with a small whitespace margin on either side. A small punch-hole sits on
the centerline near the top point of the star, and a loop of silver string
is threaded through it so the finished star can hang.

## Role Assignments

There are four roles. Each person owns a distinct part of the build so the
sample can move smoothly from one to the next.

| Role       | Tool / Responsibility                | Task on this project                                                                 |
| ---------- | ------------------------------------ | ------------------------------------------------------------------------------------ |
| **Folder** | Folds the paper                      | Folds the yellow paper using the standard five-point-star fold sequence so the star is five-way symmetric when cut. |
| **Marker** | Writes / draws                       | Draws the straight diagonal cut line on the folded paper and writes **FIRMWARE** across the upper body of the star, plus marks the punch-hole position near the top point. |
| **Cutter** | Holds the scissors                   | Makes the single straight cut to release the star, punches the marked hole near the top point, threads a loop of silver string through the hole, and unfolds the finished star. |
| **Bus**    | Moves the sample between teammates   | Carries the sample forward only: Folder → Marker → Cutter → final display. The flow is one-way; the Bus never returns the sample to a previous step. |

## Steps

The pipeline is **one-way**: each role finishes its work and hands the
sample forward via the Bus. The sample never returns to a previous step, so
each role must complete its task correctly before passing it on.

1. **Folder** takes a sheet of yellow paper and performs the standard
   five-point-star fold sequence (fold in half, then make the angled folds
   that bring the edges together into a narrow wedge with five-fold
   symmetry), then hands it off (still folded).
2. **Bus** carries the folded wedge forward from the Folder to the Marker.
3. **Marker** draws the single straight diagonal cut line across the folded
   wedge that will release the star when cut, marks the punch-hole position
   near what will become the top point of the star, and notes on the back
   where **FIRMWARE** will be written across the upper body of the star
   once unfolded — horizontally on a single line in all capital letters,
   letter-spaced to span the widest part of the star with a small
   whitespace margin on either side.
4. **Bus** carries the marked, folded wedge forward from the Marker to the
   Cutter.
5. **Cutter** makes the single straight cut along the line drawn by the
   Marker, punches the marked hole near the top point, threads a loop of
   silver string through the punch-hole and ties the ends together, then
   unfolds the finished star and writes **FIRMWARE** across the upper body
   following the placement noted by the Marker.
6. **Bus** carries the finished star forward from the Cutter to the final
   display, where the yellow five-pointed star with **FIRMWARE** across the
   upper body and a silver hanging string is shown.
