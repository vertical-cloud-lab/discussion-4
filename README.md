# discussion-4

Text-only (ASCII) paper-craft design artifacts. Each design is built by four
roles — **Folder**, **Marker**, **Cutter**, **Bus** — operating as a strict
one-way pipeline: Folder → Marker → Cutter → display. The Bus only ever
carries the sample **forward**, never back to a previous step.

## Designs

Original examples:

- Pink paper heart with `HARDWARE` written across the top — see
  [vertical-cloud-lab/discussion-4#3](https://github.com/vertical-cloud-lab/discussion-4/pull/3).
- Red folded square with corner labels, diamond cutouts, edge notches, and an
  orange pipe cleaner threaded through the upper diamonds — see
  [vertical-cloud-lab/discussion-4#3](https://github.com/vertical-cloud-lab/discussion-4/issues/3).

Additional examples in the same style:

- Blue snowflake with `SOFTWARE` — see [`SNOWFLAKE.md`](./SNOWFLAKE.md)
  (six-fold wedge, fold + cut only, like the heart).
- Yellow five-pointed star with `FIRMWARE` and a silver hanging string
  threaded through a punch-hole near the top point — see
  [`STAR.md`](./STAR.md) (fold, cut, punch, thread).
- Purple butterfly with `DRIVERS` and a yellow pipe cleaner threaded through
  two upper-wing diamond cutouts as antennae — see
  [`BUTTERFLY.md`](./BUTTERFLY.md) (fold, cut, thread, like the pipe-cleaner
  square).
